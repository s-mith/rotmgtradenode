## Install on Windows

1. Download the `.exe` file under **Assets** below.
2. If your browser says the file "isn't commonly downloaded", keep it. In Edge: **…** → **Keep** → **Show more** → **Keep anyway**. In Chrome: **Keep**.
3. Double-click it. The app is not signed yet, so Windows says **"Windows protected your PC"**: click **More info**, then **Run anyway**.
4. It installs for your Windows user, with no administrator password, and opens the setup.

Windows 11 with Smart App Control on cannot run unsigned apps; see the FAQ in the app's Help page.

Already installed? The app updates itself, so you do not need this download.

On Linux, download the `.AppImage`, make it executable (`chmod +x`), and run it.
